# Hero Image Required

## hero-bg.jpg

Please add a high-quality hero background image for the homepage.

**Requirements:**
- Filename: `hero-bg.jpg`
- Minimum size: 1920px width
- Subject: Campfire scene, kids laughing, or sunset over camp
- Format: JPG (optimized for web, under 500KB recommended)

**Fallback:**
Until the image is added, the hero section will display with a brand blue gradient background.
